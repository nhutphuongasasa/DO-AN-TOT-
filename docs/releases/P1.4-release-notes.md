# P1.4 – Burst/Flow Feature CSV Export

## Scope

- Export one validated row per Burst using the P1.3 Burst Statistics schema.
- Export one validated aggregate row per Flow using the P1.3 Flow Statistics schema.
- Preserve schema field order and version; represent undefined numeric values as empty CSV cells.
- Header-only CSV is produced for empty input.
- Keep session/Flow identifiers for lineage only; they are not model features.
- Do not inspect packet payloads or choose model-specific padding, truncation, scaling, or labels.

## Public API

- `export_burst_features_csv(bursts, path)`
- `export_flow_features_csv(flows, path)` — each element in `flows` is the Burst collection for one Flow.

Both functions create parent directories and return the destination `Path`. Input is validated through the P1.3 statistics calculators before rows are written.

## Validation

Run `./start.sh` or, with the project virtual environment already prepared, `./run_tests.sh`.
