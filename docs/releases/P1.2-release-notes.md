# P1.2 – Burst Integration Release Notes

## Implemented

- Integrated Flow finalization with the existing ML candidate gate and Burst primitives.
- Added a configurable baseline: 2 packets, 0.0-second minimum duration, and 0.5-second idle-gap boundary.
- Finalizes TCP Flows at capture-session close without changing FIN/RST semantics.
- Finalizes UDP Flows on existing idle expiration and capacity eviction paths.
- Prevents repeated finalization by Flow ID.
- Exposes Burst records through `PacketProcessor.bursts` and `ReplayResult.bursts`.
- Added JSONL/TSV Burst writers and PCAP replay CLI options.
- Added replay-path tests and a real Scapy-PCAP integration test.

## Validation in this build environment

`./run_tests.sh`: **153 passed, 3 skipped**.

The skipped tests are:

1. Real Scapy PCAP Burst integration – Scapy is not installed in this build environment.
2. DNS parser Scapy test – Scapy is not installed in this build environment.
3. Live NIC integration – requires explicit `APPID_RUN_LIVE_NIC_TEST=1` and root privileges.

The PCAP replay orchestration test uses a controlled reader and verifies that packets
flow through `replay_pcap()`, Flow tracking, candidate admission, Burst segmentation,
and JSONL/TSV output. The separate real-PCAP integration test is included but must
be run in the target Linux environment after installing project dependencies.

This release does not claim live-NIC acceptance or ML model evaluation.
