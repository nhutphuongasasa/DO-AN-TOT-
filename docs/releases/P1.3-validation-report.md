# P1.3 – Validation Report

## Implemented

- `BurstStatistics` and `compute_burst_statistics()` for packet length,
  inter-arrival time, direction counts/bytes, duration and lineage.
- `FlowStatistics` and `compute_flow_statistics()` for single-Flow aggregation.
- `BurstSequence` and `build_burst_sequence()` for stable Burst/packet ordering.
- Versioned schema constants and field lists.
- Input checks for finite timestamps, non-negative lengths/gaps, valid direction,
  duplicate packet/Burst indexes, consistent packet counts/byte totals, mixed
  Flow lineage and chronological Burst ordering.
- A single `start.sh` entry point for Linux setup, dependency verification,
  compile checks, targeted Ruff lint, and the complete pytest suite. Live-NIC
  capture is opt-in via `--live`.
- Existing Burst JSONL/TSV serialization was left unchanged.

## Skips / limitations

- Real Scapy PCAP integration skipped because Scapy is not installed in this
  build container. The updated PCAP integration test now also validates P1.3
  Burst/Flow statistics and sequence output. It must be run on the user's Linux
  machine, where Scapy was present in the previous P1.2.1 acceptance log.
- Scapy DNS parser test skipped for the same missing dependency.
- Live-NIC test skipped by design; it is opt-in and requires a configured NIC
  and capture permissions.
- Ruff is not installed in this build container, so the lint command could not
  be run here. `start.sh` installs Ruff through the project's `[dev]` extra and
  runs it on the P1.3 files on the target machine.
