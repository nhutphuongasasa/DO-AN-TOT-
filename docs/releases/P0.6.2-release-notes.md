# P0.6.2 — TCP Reassembly

## Implemented

- Added independent `appid.sni.tcp_reassembly.TCPReassembler`.
- Reassembles contiguous TCP payload bytes per Flow ID and direction.
- Handles segmentation, out-of-order segments, retransmission, overlapping
  segments (first-seen byte wins), and 32-bit sequence-number wraparound.
- Separates forward and backward stream buffers.
- Adds configurable stream-count, per-stream/total buffer, gap, segment-size,
  and idle-timeout limits.
- Adds explicit idle cleanup, per-Flow cleanup, and RST cleanup.
- Added unit tests in `tests/unit/sni/test_tcp_reassembly.py`.
- Added design and limitation details in
  `docs/architecture/tcp-reassembly-design.md`.

## Compatibility guarantees

- DNS implementation and tests are not modified by this milestone.
- P0.6.1 TLS/SNI parser implementation and tests are not modified.
- The reassembler is not yet connected to `PacketProcessor` or live capture;
  live SNI identification is therefore not claimed in P0.6.2.

## Validation

Validation is recorded in `docs/IMPLEMENTATION_NOTES.md`. The package must be
run with the project's Linux setup script to execute the complete Scapy-backed
suite in the target environment.
