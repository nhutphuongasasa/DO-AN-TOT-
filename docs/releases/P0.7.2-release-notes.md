# P0.7.2 — UDP Protocol Identification

## Added

- Stateless UDP datagram classifier for DNS, DHCPv4, NTP, STUN and QUIC Initial candidates.
- Structural validation plus corroborating port checks; no port-only protocol claims.
- Explicit `UNKNOWN` results for empty, malformed, unsupported or ambiguous datagrams.
- QUIC candidate label with reduced confidence, explicitly not a decrypted/validated QUIC result.
- Unit tests for supported signatures and negative/false-positive cases.

## Scope boundary

This milestone identifies UDP protocol metadata only. It does not classify the
six dataset application labels, modify DNS/SNI behavior, connect UDP tracking
to live capture, decrypt QUIC, or extract SNI from QUIC. Those are later stages.
