# P0.7.1 — UDP Flow Tracking

## Added

- Dedicated `src/appid/udp/` package with bounded UDP pseudo-flow tracking.
- Canonical bidirectional session-scoped UDP 5-tuple identity.
- Forward/backward/unknown datagram and byte counters.
- Explicit LAN-subnet direction policy; ambiguous direction remains UNKNOWN.
- Configurable idle timeout, maximum active-flow count, cleanup, flow close,
  and session close.
- Unit tests for accounting, direction, identity, expiry, capacity and lifecycle.

## Preserved

- Existing DNS source and behavior.
- Existing TLS ClientHello/SNI parser.
- Existing P0.6.2 TCP Reassembly implementation.
- Existing capture and PacketProcessor wiring; P0.7.1 is not yet connected to
  live capture or used for application identification.

## Limitations

No UDP protocol classifier, QUIC Initial parser, QUIC SNI extraction, or
application mapping is included. UDP payloads are not stream-reassembled.
