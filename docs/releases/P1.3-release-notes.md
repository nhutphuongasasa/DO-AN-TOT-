# P1.3 – Burst Statistics and Sequence Schema

## Scope

- Added versioned Burst statistics, Flow-level aggregation and chronological
  Burst sequence representation.
- Preserved existing Flow/session identity and explicit FORWARD/BACKWARD/UNKNOWN
  direction values.
- Kept calculations payload-free and left the existing Burst JSONL/TSV output
  contract unchanged.
- Added input consistency checks for packet counts, byte totals, timestamps,
  directions, gaps, Flow lineage and duplicate Burst indexes.
- Added `start.sh` as the single setup/verification/test entry point. Live-NIC
  capture remains explicitly opt-in via `--live`.

## Validation

Results are recorded in the P1.3 handover report after running `./start.sh`.
The live-NIC test is not part of the default test run.
