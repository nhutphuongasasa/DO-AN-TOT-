## Focused QUIC tests

Command:

```bash
PYTHONPATH=src python -m pytest -q tests/unit/udp/quic
```

Result: **12 passed**.

Coverage:

1. RFC 9001 v1 client Initial key/IV/header-protection key vector.
2. QUIC v1 Initial header parsing and 2-byte varint decoding.
3. Header-protection removal, packet-number decode, AES-GCM decrypt and
   ClientHello SNI extraction.
4. Server Initial decrypt with supplied original DCID.
5. AEAD authentication failure does not emit SNI.
6. PING and CRYPTO frame parsing.
7. Out-of-order CRYPTO reassembly and conflicting-overlap rejection.
8. Unsupported Initial frame rejection.
9. Server Initial without original DCID is rejected and does not poison
   connection context.
10. CONNECTION_CLOSE frame parsing.
11. ClientHello split across two out-of-order CRYPTO frames / Initial packets.
12. Same-offset CRYPTO retransmission/extension preserves already buffered bytes.
