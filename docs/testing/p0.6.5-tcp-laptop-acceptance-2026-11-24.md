## Acceptance interpretation

**P0.6.5 TCP AppID is laptop-verified for a short live run**, including DNS/SNI agreement for all five named applications. The evidence demonstrates the integrated live pipeline on the selected NIC.

Do not overstate this result:

1. The 180-second configured run was stopped after 11 seconds, so long-duration stability/soak is still open.
2. The log proves five applications were identified through DNS and/or TCP SNI, and explicitly shows DNS+SNI agreement for the five observed Flows. It does not prove that every app is always identified by SNI alone.
3. 61 SNI hostnames were unmapped and 5 SNI parse errors were counted; investigate only with representative safe fixtures/log metadata if these affect target traffic.
4. ECH detections were zero in this short capture; this does not establish ECH support or absence on the network.
5. UDP Flow Tracking remains a separate standalone component; UDP protocol/AppID and QUIC parsing are not part of this TCP acceptance.
