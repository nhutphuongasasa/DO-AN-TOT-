## Test coverage added

- Authenticated QUIC Initial creates a distinct QUIC connection and indexes
  its DCID/SCID.
- Server Initial observed on a different UDP 5-tuple links to the connection
  using an already-indexed CID.
- Invalid AEAD tag does not create a connection or CID mapping.
- QUIC connection idle cleanup removes its CID aliases.
- QUIC connection capacity evicts the oldest connection and its aliases.
- DNS-first early exit is the current runtime contract; QUIC SNI is reached
  only when DNS is unresolved. Historical fusion tests are superseded by the
  DNS-first regression tests dated 2026-11-26.
- UDP Flow idle expiry is independent of TCP Flow lifecycle.
- Active UDP Flow capacity is bounded.
- QUIC analysis can be disabled without disabling UDP protocol identification.
- Synthetic PacketProcessor integration validates UDP candidate → QUIC v1
  Initial decrypt → ClientHello SNI → `youtube` AppID, with
  `application_protocol=QUIC_INITIAL`.
