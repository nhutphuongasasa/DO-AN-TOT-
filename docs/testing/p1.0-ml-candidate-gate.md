# P1.0 — ML Candidate Gate Tests

## Covered behavior

- DNS/SNI-classified Flow is rejected before ML admission.
- Missing observation policy returns `PENDING`; no minimum thresholds are assumed.
- Explicit policy admits an unresolved Flow and preserves the existing `session_id` / `flow_id`.
- Packet order is deterministic by `(timestamp, packet_index)`.
- Direction labels are copied from FlowTracker; they are not recomputed.
- One-way Flow is retained with a quality flag.
- Observation and packet collection are immutable.
- Duplicate packet indexes remain pending until a deduplication policy is decided.
- Non-finite timestamps and invalid metadata are rejected.
- Packet-count and duration policy checks return `PENDING` when not yet satisfied.

## Explicitly deferred

- Burst boundary policy and segmentation.
- Model feature/tensor schemas and model inference.
- Project-wide minimum observation thresholds.
