# P1.2 – Burst Integration

## Baseline policy

| Setting | Value |
|---|---:|
| Minimum Flow packets | 2 |
| Minimum Flow duration | 0.0 seconds |
| Burst idle-gap boundary | 0.5 seconds |
| TCP finalization | Capture-session close |
| UDP finalization | Idle expiration / capacity eviction |
| Output | JSONL and TSV (optional PCAP replay flags) |

These are initial engineering defaults, not empirically optimized application
classification thresholds. The `PacketProcessor` accepts explicit policy
objects to override them. The standalone `evaluate_ml_candidate()` method
continues to require an explicit policy, preserving its previous contract.

## Lifecycle and exactly-once behavior

- UDP flows returned by `FlowTracker.expire_udp_flows()` are finalized before
  processing the current UDP packet.
- UDP flows removed for active-flow capacity are finalized immediately.
- TCP flows remain active until capture-session close; FIN/RST handling is not
  changed by this phase.
- A finalized Flow ID is recorded to prevent repeated candidate evaluation.
- Only admitted, completed Flows are segmented. Classified DNS/SNI Flows are
  rejected by the existing candidate gate.
- Active Flows do not produce partial Burst snapshots.

## PCAP replay

`replay_pcap()` closes the processor before collecting `ReplayResult.bursts`,
so TCP flows are finalized at the same session boundary as the existing replay
lifecycle. Optional `burst_jsonl` and `burst_tsv` arguments write output files.
The CLI exposes these as `--burst-jsonl` and `--burst-tsv`.

## Output schema

Both output formats contain: `session_id`, `flow_id`, `burst_index`,
`direction`, `start_ts`, `end_ts`, `duration_seconds`, `packet_count`,
`total_bytes`, and `inter_burst_gap_seconds`.

## Validation scope

The PCAP replay integration test drives synthetic packet records through the
shared replay function and verifies Flow lineage, direction boundaries, the
configured idle-gap boundary, Burst records, and JSONL/TSV serialization.
This is an integration test of the replay orchestration, not a live-NIC test
or an ML model evaluation.

## Real-PCAP acceptance test

`tests/integration/test_pcap_burst_pipeline.py` writes an Ethernet/IPv4/TCP
PCAP with Scapy and replays it through the real `PcapReader` and packet parser.
It is automatically skipped when Scapy is not installed. Run it on the target
Linux environment after installing the project dependencies:

```bash
.venv/bin/python -m pytest -q tests/integration/test_pcap_burst_pipeline.py
```
